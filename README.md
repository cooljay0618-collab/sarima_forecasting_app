# SARIMA 수요예측 대시보드

한국의 전자상거래 수입/수출 데이터를 기반으로 미래 수요를 예측하는 SARIMA 시계열 분석 대시보드입니다.

## 🎯 주요 기능

- **실시간 데이터 분석**: 146개월(2014.01 ~ 2026.02)의 기본 데이터 내장
- **데이터 업로드**: Excel 파일로 새로운 데이터 누적 업데이트
- **SARIMA 모델**: 비계절성 + 계절성(12개월) 시계열 분석
- **신뢰구간**: 95% 신뢰도의 예측 범위 제공
- **대화형 차트**: 마우스 스크롤 확대/축소, 드래그 이동
- **성능 평가**: MAPE, MAD, RMSE 등 다양한 평가 지표

## 📊 데이터 구조

### 기본 데이터
- **수입 데이터**: 전자상거래 수입 금액 (146개월)
- **수출 데이터**: 전자상거래 수출 금액 (146개월)
- **단위**: USD (달러)

## 📖 사용 방법

### Step 1: 데이터 유형 선택
좌측 사이드바 "📊 데이터 유형"에서 수입 또는 수출 데이터 선택

### Step 2: SARIMA 파라미터 설정
- **비계절성** (p, d, q): 기본값 1, 1, 1
- **계절성** (P, D, Q): 기본값 1, 1, 1 (m=12)

### Step 3: 예측 기간 설정
1~36개월 범위에서 선택 (기본값: 12개월)

### Step 4: 예측 실행
페이지 우측 상단의 "🔮 예측 실행" 버튼 클릭

### Step 5: 결과 확인
- 과거 데이터 추세 차트
- 성능 지표 (MAPE, MAD, RMSE)
- 예측값 및 신뢰구간
- 예측값 상세 테이블

## 🔧 SARIMA 파라미터 설명

### 비계절성 (Non-Seasonal)
- **p (AR 차수)**: 과거 값의 영향 정도 (추천: 0~3)
- **d (차분 횟수)**: 추세 제거 (추천: 0~2)
- **q (MA 차수)**: 오차항 영향 (추천: 0~3)

### 계절성 (Seasonal)
- **P, D, Q**: 12개월 주기에서의 비계절성 파라미터
- **m**: 계절성 주기 (고정값: 12)

## 📈 성능 지표

| 지표 | 설명 | 평가 기준 |
|------|------|----------|
| MAPE | 평균 절대 백분율 오차 | 10% 이하 = 매우 좋음 |
| MAD | 평균 절대 편차 | 낮을수록 좋음 |
| RMSE | 제곱평균제곱근 오차 | 낮을수록 좋음 |
| AIC | 아카이케 정보 기준 | 낮을수록 좋은 모델 |
| BIC | 베이지안 정보 기준 | 낮을수록 좋은 모델 |
